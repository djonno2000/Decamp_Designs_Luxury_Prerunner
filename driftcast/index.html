The cheap, plentiful RWD donors that built drift culture — S-chassis, JZX, Skylines — are priced out. DriftCast is the answer: one wide, low, stiff tube chassis that takes any common engine, gearbox and diff, under a quick-swap plastic skin. The thesis

One chassis, swap everything else

Build the right car from the ground up instead of cutting up an increasingly rare production donor.

  • 01

    Wide, low, stiff tube frame. Low CG, wide track, a triangulated spaceframe with the cage as integral structure — a flexy chassis is an untunable spring.

  • 02

    Swappable engine-mount plates. A common chassis-side interface plus engine-specific adapter plates — change the plates, change the engine family.

  • 03

    Common bellhousing & diff mount. Adapter bellhousings per engine, a standard adjustable trans crossmember, and one diff mount taking Ford 9", Toyota or Nissan rears.

  • 04

    Drift geometry from scratch. 60°+ steering angle and clean bump-steer designed in — not retrofitted with an angle kit onto geometry that never wanted to slide.

  • 05

    Quick-swap plastic skin. A hit is cosmetic only: peel the panel, fix the tube, re-skin. The car always looks new and never rusts.

  • 06

    The smash-and-replace economy. Cheap replacement zones, universal LED lights designed into the panels, a spare set in the trailer for a five-minute swap between runs.

The differentiator

The plastic skin system

  • // The tube frame carries all structural load; panels carry none — so they're cheap, thin and replaceable.
  • // Plastic deforms and pops back instead of crumpling — many hits leave the panel reusable.
  • // Moulded-in colour or wrap — scratches don't rust, no panel-beat-and-respray cycle.
  • // Split into independent zones (bar, guards, doors, quarters) on one standard mount — replace only what you hit.
  • // Materials to evaluate: ABS / ASA / polypropylene body, polycarbonate (Lexan) glazing, quarter-turn fasteners for pit swaps.
Panel zones

Replace a zone, not a car

Front bar · guards · doors · rear quarters · rear bar — each a standalone bolt-on. A smashed light is a cheap universal off-the-shelf swap, anywhere.
